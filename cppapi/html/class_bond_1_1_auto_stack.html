Detailed Description

template<typename ValueType>
class Bond::AutoStack< ValueType >

A stack whose elements are automatic variables.

Pushing a value onto the stack returns an Element that must be kept alive for as long as the value should remain on the stack; destroying the Element pops the value. Elements must be destroyed in reverse order of creation and must not outlive the stack. The stack cannot be copied or moved.
