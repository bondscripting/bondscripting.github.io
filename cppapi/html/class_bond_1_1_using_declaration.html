Detailed Description

Represents a using-declaration that aliases a single symbol into local scope.

Participates in symbol lookup as an ordinary Symbol so that it can be linked into the intrusive scope list like any other local declaration, but Symbol::Resolve() causes lookups to transparently unwrap it to the aliased target, so no other part of the compiler ever observes a UsingDeclaration.
