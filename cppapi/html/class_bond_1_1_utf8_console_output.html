Detailed Description

Makes a Windows console display UTF-8 output for the lifetime of this object.

The constructor switches the console's output code page to UTF-8. The destructor flushes stdout and stderr, then restores the original code page, since the code page belongs to the console and would otherwise persist after the program exits. Console input is not affected. On other platforms, this class does nothing.

This is intended for applications that own their console, such as the Bond tools. A library embedding Bond should leave the console configuration to its host application.
