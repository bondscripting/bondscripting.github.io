Detailed Description

The activation record of a function invoked by a VM.

A StackFrame gives access to the arguments and return value of a function call. Native functions receive the StackFrame of their own invocation, through which they read their arguments with GetArg() and set their return value with SetReturnValue(). StackFrames are created and destroyed by the VM and by InvocationStackFrame; they are not constructed directly by applications.

Collector & Bond::StackFrame::GetCollector ( )

Returns the Collector whose Collectable objects are destroyed when the stack frame is popped off of the VM's call stack.

A native function that allocates memory or objects on behalf of the calling Bond function typically registers them with the Collector of the caller's stack frame, obtained with VM::GetCallerStackFrame(), so that they live until the caller returns.

template<typename ReturnType>
void Bond::StackFrame::SetReturnValue ( const ReturnType & returnValue)

Sets the return value of the invoked function.

Integers smaller than 32 bits are widened to 32 bits according to the Bond return type, and enums are stored as their underlying type. When BOND_RUNTIME_CHECKS_ENABLED is non-zero, a Bond::Exception is thrown if ReturnType does not match the return type of the function.
