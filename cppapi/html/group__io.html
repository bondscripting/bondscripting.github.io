◆ NormalizePath()

BOND_API void Bond::NormalizePath ( const StringView & directory,
const StringView & path,
Vector< char > & result )

Lexically normalizes the path formed by joining a directory and a path.

The result uses '/' separators, contains no "." segments or repeated separators, and has "segment/.." pairs collapsed. Leading ".." segments are kept on relative paths and dropped at the root of absolute paths. A drive letter prefix, a root separator and a UNC "//" prefix are preserved. An empty result is written as ".". No file system calls are made, so the names need not refer to files, and symbolic links are not resolved.

Parameters
directoryA directory to prepend to path, with an implied separator between them. It may be empty.
pathThe path to be normalized.
resultReceives the null terminated normalized path. Its previous contents are discarded. No memory is allocated other than by result.
