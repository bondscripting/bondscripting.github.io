Detailed Description

Provides a program's command line arguments encoded in UTF-8.

On Windows, the narrow argv passed to main is encoded in the ANSI code page, so non-ASCII arguments are altered or lost. CommandLineArgs retrieves the UTF-16 command line from the operating system and converts each argument to UTF-8. If that fails, it falls back to the given argv. On other platforms, argv is already UTF-8 and is returned unchanged.
