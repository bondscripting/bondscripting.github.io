Detailed Description

Represents a using-directive that opens a namespace's symbols into local scope.

Never enters a symbol table; it is instead threaded into its enclosing local scope's list of opened namespaces (via its own dedicated next-pointer, separate from the ListParseNode next-pointer used to place it among the enclosing statement list) and consulted as a fallback by Symbol::FindSymbol.
