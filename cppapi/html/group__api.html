Detailed Description

These types and functions bind native C++ functions to Bond and give access to the Bond Standard Library.

Typedef Documentation

◆ NativeFunction

typedef void(*) Bond::NativeFunction(StackFrame &frame)

A C++ function that implements a function declared native in Bond.

The function reads its arguments from, and sets its return value through, the StackFrame of its invocation.

See also
StackFrame::GetArg, StackFrame::SetReturnValue

Variable Documentation

◆ INCLUDE_FILE_INDEX

BOND_API const DataViewIndex Bond::INCLUDE_FILE_INDEX
extern

An index of the source of the include files of the Bond Standard Library, which are embedded in the Bond library.

The files are named "debug.bond", "io.bond", "math.bond", "memory.bond", "string.bond" and "type.bond". The index can be used to resolve include directives in Bond scripts without accessing the file system, e.g. with a MemoryStreamFactory.
