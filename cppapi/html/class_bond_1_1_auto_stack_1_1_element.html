Detailed Description

template<typename ValueType>
class Bond::AutoStack< ValueType >::Element

A single value on an AutoStack, owned by the scope that pushed it.

An Element is pushed onto its stack when it is constructed and popped when it is destroyed. An Element cannot be copied or moved.
