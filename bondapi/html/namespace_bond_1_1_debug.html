◆ Break()

void Bond::Debug::Break ( )

Stops the program in the native debugger if one is attached. Does nothing otherwise, so calls can be left in scripts that run without a debugger.

The debugger stops in, or just below, the native function Bond::Debug::Break. Its frame parameter is the Bond::StackFrame of the call, and frame.mVm gives the whole Bond call stack.

◆ IsDebuggerPresent()

bool Bond::Debug::IsDebuggerPresent ( )

Returns whether a native debugger is attached to the process.

Detection is supported on Windows, Cygwin, Linux and macOS. On other platforms, false is always returned and Break does nothing.
